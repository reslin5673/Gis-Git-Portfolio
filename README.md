## 🌊 Featured Project

### Coastal Flood Modelling & Risk Assessment — Quelimane, Mozambique

A coastal flood modelling and risk assessment project investigating flood behaviour and structural mitigation using **openLISEM, QGIS, and geospatial data**.

#### Key components

- Flood onset detection at a critical location
- Maximum water-level analysis
- Rainfall and coastal boundary-condition analysis
- Structural mitigation scenario testing
- 4.0 m dike mitigation assessment
- Sea-level-rise scenario analysis
- Raster and vector geospatial processing
- Comparative flood mapping in QGIS
- Reproducible project organisation using Git and GitHub

**Project location:** Quelimane, Mozambique
