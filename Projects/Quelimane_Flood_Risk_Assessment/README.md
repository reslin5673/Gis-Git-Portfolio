# Quelimane Flood Risk Assessment

## Overview

Flood modelling and risk assessment project for Quelimane, Mozambique, using the open-source hydrological modelling tool openLISEM.

## Objectives

- Simulate flooding using T50 rainfall and coastal boundary conditions.
- Detect flood onset at the Campo CFM football stadium.
- Assess whether flooding is influenced by rainfall or sea-level rise.
- Test a 4.0 m dike as a flood mitigation scenario under 4.7 m sea-level rise.
- Visualize and compare flood extent using QGIS.

## Tools

- openLISEM
- QGIS
- Git & GitHub

## Study Area

Quelimane, Mozambique


## Methodology

1. Prepare Rainfall and Terrain Data
2. Set up the flood model
3. Run the flood simulation
4. Analyse the flood results
5. Visualize the results using QGIS
